Capture a Figma canvas

Capture Figma's rendered pixels alongside its inspectable layers, exact geometry, styles, and variable bindings.

The plugin is bound to this server. Rebuild it with HANDOFF_PUBLIC_URL to change the destination.

For a complete canvas, choose all top-level frames on the current Figma page.

Possible frame replacements

A new frame with the same name may replace an earlier screen. Choose only the pairs that are the same screen. Unmatched frames stay separate.

Figma does not store CSS margins. Handoff records source padding and spacing as exact values, and labels geometric gaps as measured margins.
